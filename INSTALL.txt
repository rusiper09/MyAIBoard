MyAIBoard 설치 안내
====================

MyAIBoard는 Windows 바탕화면에 떠 있는 메모 위젯입니다.
Claude Code나 Codex 같은 AI에게 "aiboard에 추가해"라고 말하면 AI가 이 보드에 메모를 남깁니다.


1. 준비물
---------
- Windows 10 또는 11 (64비트)
- (선택) AI와 연결하려면 아래 중 하나 이상
    - Claude Code (명령어 claude 가 실행되는 상태)
    - Codex 데스크톱 앱 또는 codex CLI
- .NET 등 다른 프로그램은 설치할 필요가 없습니다. 압축 파일에 모두 들어 있습니다.


2. 내려받기
-----------
1) https://github.com/rusiper09/MyAIBoard/releases 에 들어갑니다.
   (저장소가 비공개라면 저장소 주인에게 접근 권한을 받아야 보입니다.)
2) 최신 버전의 MyAIBoard-<버전>-win-x64.zip 을 내려받습니다.
3) 원하는 폴더에 압축을 풉니다. (예: 바탕화면\MyAIBoard-0.1.0)
   압축을 푼 폴더는 설치가 끝나면 지워도 됩니다.


3. 설치
-------
방법 A) 압축을 푼 폴더에서 install.ps1 을 마우스 오른쪽 버튼으로 누르고
        "PowerShell에서 실행"을 고릅니다.

방법 B) 압축을 푼 폴더의 주소창에 powershell 이라고 입력해 PowerShell을 연 다음
        아래 명령을 붙여 넣습니다.

        powershell -ExecutionPolicy Bypass -File install.ps1

설치 중에 다음을 물어봅니다. Enter(=예)를 누르면 연결됩니다.
- "Connect Claude Code to the board?"  -> Claude Code와 연결
- "Connect Codex to the board ...?"    -> Codex와 연결
  (Codex를 연결하면 ~/.codex/AGENTS.md 에 aiboard 사용 안내가 몇 줄 추가됩니다.)
  컴퓨터에 해당 AI가 없으면 "not found"라고 나오고 넘어갑니다.

설치가 끝나면 화면 오른쪽 위에 위젯이 나타납니다.
- 설치 위치: %USERPROFILE%\.myaiboard  (프로그램, 메모 데이터, 설정이 모두 여기 있습니다)
- 시작 메뉴에 "MyAIBoard" 바로가기가 생기고, Windows에 로그인하면 자동으로 실행됩니다.
  자동 실행을 원하지 않으면 위젯 메뉴(⋯)에서 "Windows 시작 시 실행"을 끄세요.


4. AI와 연결 확인
-----------------
- 이미 열려 있던 Claude Code 세션은 닫고 새로 시작해야 연결됩니다.
- Codex 데스크톱 앱은 트레이까지 완전히 종료한 뒤 다시 켜세요.
- AI에게 "aiboard에 테스트 메모 추가해"라고 말해 보세요.
  위젯에 메모가 나타나면 성공입니다. (Claude는 주황, Codex는 민트, 직접 쓴 메모는 파랑)

설치할 때 연결하지 않았다면 install.ps1 을 다시 실행해서 "예"를 고르면 됩니다.
직접 등록하려면:
    claude mcp add --scope user myaiboard -- "%USERPROFILE%\.myaiboard\bin\MyAIBoard.Mcp.exe"
    codex mcp add myaiboard -- "%USERPROFILE%\.myaiboard\bin\MyAIBoard.Mcp.exe"
  (PowerShell에서는 %USERPROFILE% 대신 $env:USERPROFILE 을 씁니다.)


5. 기본 사용법
--------------
- 새 메모: 위젯의 + 버튼, 또는 어디서나 Ctrl+Alt+N
    제목 입력 -> Enter로 본문 이동 -> Ctrl+Enter 저장 / Esc 취소
- 편집: 메모를 더블클릭
- 삭제: 메모에 마우스를 올리면 나오는 휴지통 버튼 (5초 안에 "되돌리기" 가능)
    삭제한 메모는 메뉴 -> 휴지통에 30일간 보관됩니다.
- 검색: 돋보기 버튼 또는 Ctrl+F. "#태그"로 태그 검색도 됩니다.
- 해시태그: 제목이나 본문에 #버그 처럼 쓰면 태그가 되고, 누르면 그 태그 메모만 보입니다.
    AI가 쓴 메모에는 AI가 작업 중인 폴더 이름이 태그로 자동으로 붙습니다.
- 링크: 작은따옴표로 감싼 경로나 주소는 누를 수 있습니다. 예) 'C:\Work\보고서.docx'  'https://example.com'
- 메뉴(⋯ 또는 위젯 오른쪽 클릭): 정렬, 창 모드(바탕화면 고정/항상 위/일반),
    내보내기(JSON/Markdown), 가져오기, 휴지통, 종료
- 위젯을 닫아도(Alt+F4) 숨겨질 뿐입니다. 작업 표시줄 트레이 아이콘을 누르면 다시 나옵니다.


6. 업데이트
-----------
새 버전 zip을 내려받아 압축을 풀고 install.ps1 을 다시 실행하면 됩니다.
메모와 설정은 그대로 유지됩니다.
열려 있는 AI 세션은 새로 시작해야 새 버전을 씁니다.


7. 제거
-------
압축을 푼 폴더(또는 아무 버전의 zip)에서:

    powershell -ExecutionPolicy Bypass -File uninstall.ps1

위젯, 바로가기, 자동 실행, AI 연결을 지웁니다. 메모 데이터는 남겨 둡니다.
메모까지 모두 지우려면:

    powershell -ExecutionPolicy Bypass -File uninstall.ps1 -RemoveData


8. 문제가 생기면
----------------
- Ctrl+Alt+N 이 안 됨
    다른 프로그램이 같은 단축키를 쓰는 경우입니다. 위젯 메뉴의 "새 메모" 옆에 "사용 불가"가 보입니다.
    %USERPROFILE%\.myaiboard\settings.json 의 "NewMemoHotkey" 값을 예) "Ctrl+Alt+B" 로 바꾸고
    위젯을 다시 실행하세요. (트레이 아이콘 오른쪽 클릭 -> 종료 후 시작 메뉴에서 실행)
- 위젯이 안 보임
    트레이 아이콘을 왼쪽 클릭하세요. 그래도 없으면 시작 메뉴에서 MyAIBoard를 실행하세요.
- AI가 aiboard를 모른다고 함
    4번의 연결 확인을 다시 보세요. 세션/앱을 새로 시작해야 적용됩니다.
- Codex 로그에 "MCP startup failed ... (os error 3)"
    MCP 서버 경로가 AppData 아래로 등록된 경우입니다. install.ps1 을 다시 실행해 Codex 연결을 "예"로 고르세요.
- Windows가 "알 수 없는 게시자" 경고를 띄움
    서명되지 않은 프로그램이라 처음 실행할 때 나올 수 있습니다. "추가 정보" -> "실행"을 누르세요.
